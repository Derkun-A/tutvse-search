# Тут все — Search MVP 0.5

Отдельное приложение поиска по базе сообщества «Тут все».

## Принципы MVP

- текущий `tutvse-site` не изменяется;
- Google Sheets остаётся источником данных;
- поиск и форма живут в отдельном приложении;
- опубликованные листы нормализуются через mapping-слой;
- результаты выдаются по 30 карточек с кнопкой «Показать ещё»;
- контакты раскрываются по кнопке;
- `Содержание`, `Маркетинговые отделы`, `Ответы на форму`, `Ответы с сайта` в поиск не входят.

## План

1. Mapping Google Sheets.
2. Server-side reader.
3. Search API.
4. Страница `/search`.
5. Страница `/join`.
6. Аналитика.
7. Деплой на отдельный поддомен.
